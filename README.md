# NatureCamp Website (Non-Responsive)

A static landing page website for **NatureCamp**, designed with a fixed desktop layout featuring the information of **NatureCamp**.

---

## 📸 Preview

![NatureCamp Landing Page](https://github.com/TsukiNoKame/nature-camp-website/blob/main/img/home-page.webp?raw=true)

---

## 📌 Features

* **Brand Header & Navigation**: Displays the "NatureCamp" brand logo alongside menu links (`Home`, `About`, `Services`, `Contact`).
* **Fixed/Non-Responsive Layout**: Built with a static width layout designed primarily for standard desktop viewports.

---

## 🛠️ Built With

* **HTML5**
* **CSS3**
